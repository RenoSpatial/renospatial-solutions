# CLAUDE.md

The rules for this repository live in **[AGENTS.md](AGENTS.md)** — one file, so
that Claude Code, Google Antigravity and any other agent follow the same
instructions. Read it before editing.

Then read **[PROJECT_MEMORY.md](PROJECT_MEMORY.md)** for current state, decisions
already made, and things that were tried and rejected. Update its Changelog when
you finish.

Two things that catch people out here:

1. **A full visual redesign was built and rejected.** Improve within the existing
   dark navy + gold language; do not replace it.
2. **Everything is one file** (`index.html`) with no build step, and the site
   makes **zero external runtime requests**. Keep both properties intact.
